# 1. Requisitos identificados
## REQ-001 — Dashboard Executivo

O sistema deverá disponibilizar uma visão dos principais indicadores da empresa em um único dashboard.

### Informações
- Faturamento;
- Quantidade de pedidos;
- Produção em andamento;
- Máquinas paradas;
- Chamados de manutenção;

---

## REQ-002 — Integração entre setores

As informações utilizadas no dashboard deverão permitir o relacionamento entre dados de diferentes departamentos.

### Exemplos
- Financeiro: valores faturados;
- Comercial → pedidos;
- Produção → ordens de produção;
- Manutenção → paradas de equipamentos;
