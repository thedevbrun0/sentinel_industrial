# 1. Requisitos identificados
## REQ-001 — Um sistema com cadastro único

Esse sistema deve juntar as informações sobre cada funcionário.

### Informações
- Departamento;
- Cargo;
- Treinamentos Concluídos;
- Validade de cada certificação;
- Quais máquinas está apto a operar;

---

## REQ-002 — Integração entre setores

As informações desse sistema deve estar interligado com outros departamentos.
### Exemplos

- Produção, Manutenção → saber informações dos funcionários;
- TI → cadastrar novos funcionários ao sistema ;
